This page is a simulated cvsu.edu.ph. The widget script is loaded at the bottom and should drop a green chat bubble in the bottom-right corner. Click it to open the chat overlay.

What to look for

  1. A circular green chat bubble appears in the bottom-right corner.
  2. Click it → an overlay slides in (slide-in panel on desktop ≥640px, full-screen on mobile).
  3. The iframe inside loads DIWA with no green DIWA header bar and no "Urgent concerns" footer (that's the ?embed=1 mode working).
  4. Press Esc or the × button — overlay closes, bubble reappears.
  5. Try sending a message — it should reach the API and reply.

This page sets data-diwa-open-after="3000" and data-diwa-remember="closed", so the widget auto-opens 3 s after load. Close it — refresh — it stays closed (until you press Reset dismissed flag + reload).

Direct iframe option: see /?embed=1 open directly in a new tab — same chrome-less render as inside the widget.
